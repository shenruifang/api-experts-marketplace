# 原料药立项评估团（API Project Evaluation Team）

面向原料药（API）项目的立项评估专家团，方法论底座为**五维决策模型 + 阶段门流程**。

## 方法论底座

### 五维决策模型（交集关系）

```
立项可行性 = F(市场窗口, 成本竞争力, 质量合规, 供应链可靠, 自身能力)
```

**不是加权求和，而是交集。** 任一维度的严重短板都足以使项目在整体上失去可行性。核心任务不是孤立追求某维最优，而是在识别各维硬性红线之后，寻找一个可接受的组合解。

法规与专利（准入前提）与商业化（退出条件）不在五维之列，但同样构成立项决策的必要输入。

### 三种竞争形态

| 形态 | 竞争核心 | 评估侧重 |
|------|---------|---------|
| 专利药原料药及中间体（专利期内） | 技术能力 + 质量体系 | 重工艺与质量，成本从轻；须评估专利到期后的需求断崖 |
| 首仿及专利后期原研 | **速度** | 重专利时序、注册节奏、设备改造周期与窗口的赛跑 |
| 无专利成熟品种 | **成本** | 重全成本模型、规模效应、供应链管理 |

### 阶段门流程

| 阶段 | 核心问题 | 投入 | 输出物 |
|------|---------|------|-------|
| 0 初筛 | 有什么明显不行的？ | 极低 | 候选清单 + 一页纸初筛表 |
| 1 预调研 | 窗口是否存在？ | 低 | 调研报告 + Go/No-Go |
| 2 深度调研 | 能不能赚钱？ | 中 | 立项报告 |
| 3 决策门 | 大家是否一致同意？ | 低 | 决议书（Go/Kill/Recycle/Hold） |
| 4 动态复审 | 是否还值得继续？ | 持续监控 | 复审报告 |

### 研发三报告

| 文档 | 回答 | 对应阶段 | 结论形式 |
|------|------|---------|---------|
| 项目调研报告 | 能不能做 | 第 1 阶段 | 推荐立项 / 暂缓跟踪 / 果断放弃 |
| 项目立项报告 | 值不值得做 | 第 2 阶段 | 批准立项 / 有条件批准 / 否决 |
| 项目开题报告 | 具体怎么做 | 立项批准后 | 方案科学合规可控，可进实验室 |

## 关键判定口径

### 五维红线（触发即 Kill 或 Hold）

- **市场窗口**：窗口已关闭或需求证伪
- **成本竞争力**：全成本高于市场价且无下降路径；预估物料成本超市场价一半且无收率/回收优势
- **质量合规**：杂质谱不可控；目标晶型被专利覆盖且无替代；EHS 投入不可承受
- **供应链可靠**：全球独家且无替代的起始物料；经销权被独家协议锁定；必需溶剂环保受限；起始物料不符合 ICH Q11
- **自身能力**：关键设备缺失且改造超窗口；产能利用率预计 <30%；团队无该类化学经验且拒绝外援；资金仅够 6 个月且无融资渠道

### 决策门定量阈值

| 指标 | 否决线 | 通过线 |
|------|-------|-------|
| NPV | ＜0 | ＞0 且 IRR＞WACC |
| IRR（税后全投资） | ＜12% | ＞18% |
| 投资回收期（含建设期） | ＞8 年 | ＜6 年 |
| 盈亏平衡点（产能利用率） | ＞60% | ＜50% |
| 安全边际率 | ＜15% | ＞30% |
| 悲观情景最大资金缺口 | ＞企业承受阈值 | ≤企业承受阈值 |

### 初筛一票否决链

1. **市场窗口粗判**：年需求量数量级（几十吨/几吨/几百公斤级）+ CDE 备案家数与 A 状态数
2. **自身设备硬约束**：以**现有设备**为准，不是"可改造设备"；改造超 18 个月而窗口不足 2 年直接排除
3. **成本数量级**：预估物料成本超市场可接受价格的一半且无明显收率/回收优势 → 不可行

## 使用方式

```
评估XX原料药的立项可行性，输出完整立项评估报告
帮我筛选适合我们产线的原料药品种，输出优先级立项清单
对比XX原料药的两条合成路线，量化成本、放大风险与EHS代价
我们的设备能不能做XX？沉默期资金撑不撑得住？
XX原料药卖给谁？多久能产生收入？
```

单一维度问题由主理人直调对应成员，不启动完整阶段门。

## 数据纪律

- 所有收率、成本、价格、专利到期日、需求量、供应商与客户信息必须标注来源与检索日期，查不到写「未获取」
- **严禁编造**
- 收率须区分文献收率 / 专利收率 / 小试实测收率
- 未取得用户确认的企业数据前，设备、产能、团队、资金结论一律标「待企业确认」
- 每次交付须附：假设清单、待补充清单（标注责任方）、数据来源与检索日期总表

## 关于本版本

本包为**公开精简版**，包含完整的方法论框架与团队协作机制：五维决策模型、三种竞争形态路由、阶段门 SOP、研发三报告体系、决策门定量阈值与定性红旗、初筛一票否决链，以及主理人 + 9 位成员的完整提示词。

不含任何企业内部数据、客户信息或未公开资料。方法论框架为行业通行做法的体系化整理，可直接用于原料药立项评估工作。
